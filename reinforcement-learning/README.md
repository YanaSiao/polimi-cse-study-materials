# Reinforcement Learning

This folder contains materials for **exam preparation** and **theory review** for the **Reinforcement Learning PhD course** at **Politecnico di Milano**, academic year **2025–2026**.

The course was taught by:
- Restelli Marcello
- Metelli Alberto Maria
- Papini Matteo


## Folder Contents

This folder includes:

- **Oral exam questions**  
  A collection of questions gathered from previous oral exam sessions.

- **Study materials**  
  Notes and resources used for theory review and exam preparation.

- **Suggestions**  
  Personal feedback and strategies on how to approach the course and prepare effectively for the exam.
