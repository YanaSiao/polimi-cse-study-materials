# Model Identification and Data Analysis 1 (MIDA1)

This folder contains personal study materials for the Model Identification and Data Analysis 1 course, taken during the 2024–2025 academic year of the Master’s program in Computer Science and Engineering. 

The course was taught in parallel by professors L. Piroddi and S. Formentin.



## 📂 Folder Contents

*   **`theory-questions-checklist.md`**  
    A structured concept checklist highlighting the core theoretical pillars you need to master to pass the theoretical part of the exam. Topics are ordered to logically match the flow of the lecture series.
*   **`suggestions.md`**  
    Personal feedback, strategy tips, and advice for students approaching this course for the first time. This file is designed to complement the checklist and help reduce unnecessary trial-and-error during your exam preparation.
