# Embedded and Edge AI (EEAI)

Welcome to my study space for the **Embedded and Edge AI (EEAI)** course, completed during the academic year **2025–2026**. This course was taught by the amazing **Professor Manuel Roveri**. 

This folder is designed to serve as an organized resource for anyone looking to navigate the core concepts of hardware architectures, optimization strategies, and running machine learning models at the edge.


## 📂 Folder Contents

* **`theory-summary.md`**
    This file features a curated extraction of theory questions compiled from actual EEAI exams from this academic year.
  It also integrates questions from the *Hardware Architectures for Embedded and Edge AI* course—a previous iteration taught by Professor Roveri that heavily overlaps with the modern EEAI syllabus.
  Each question is accompanied by my personal detailed solution, structured chronologically by topic order to align with the progression of the course lectures.

* **`suggestions.md`**
    A  feedback document containing my personal insights, preparation strategies, and survival tips on how to effectively study for and pass the exam.

* **`theory/` (Notes Folder)**
    This directory contains all of my conceptual study notes fully formatted in Markdown (`.md`).
    * **How to explore:** Start directly with the **`Embedded and Edge AI MOC`** (Map of Content) file. It functions as the exact epicenter of this knowledge web, providing structured,
      interactive links to every other note file in the folder.
    * **Tool Tip:** I highly recommend opening this folder inside **[Obsidian](https://obsidian.md/)** to take full advantage of backlinking and local graph visualizations for a smooth,
      engaging study experience.
