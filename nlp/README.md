# Natural Language Processing (NLP)

Welcome! This folder contains curated materials for preparing for the **Natural Language Processing (NLP)** course, 
a part of the Computer Science and Engineering Master’s degree at **Politecnico di Milano**.


## Course Context
* **Academic Year:** 2025–2026
* **Professor:** Prof. M. Carman


## Content Breakdown
Inside this directory, you will find:
* **`exam-questions.md`**: A comprehensive, topic-grouped list of exam questions ordered exactly as the material is
  presented in the lectures. 
  > *Note: These questions were compiled using two official exams from each year (2023, 2024, and 2025).*



## Study & Survival Suggestions

* **For the Exam:** Focus heavily on **factoids**. You will need to memorize specific names, abbreviations,
  exact properties of models, and their precise use cases. 
* **For the Project:** Focus on the underlying concepts and actually run the code.
  Always ask yourself: *"Is there a different way to solve this?"* In NLP, there is almost always a better, faster,
  or more ingenious way to tackle a task. 
* **Keep in Mind:** The curriculum changes slightly from year to year as new topics are introduced,
  but the core basic theory remains steady.
* **The Golden Rule**: Start early, embrace endless experimentation, and take nothing for granted!
